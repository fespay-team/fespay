# FesPay 画面プロトタイプ

学園祭・地域のお祭り向けのスマートフォン画面を試すための、React・TypeScript・Vite 製の独立したデモアプリです。[画面と操作の説明](../docs/design/Prototype.md)と[要件定義書](../docs/requirements/event_payment_requirements.md)を参照してください。既存の `apps/web` とは別に起動します。

## 起動

Node.js 20.19 以降の 20 系、または 22.12 以降と npm を用意し、リポジトリのルートから実行します。

```sh
cd prototype
npm ci
npm run dev
```

表示されたローカル URL をブラウザーで開いてください。画面はスマートフォン幅での閲覧を想定しています。ビルド確認は `npm run build` です。PowerShell で `npm.ps1` が制限される場合は、各コマンドの `npm` を `npm.cmd` に置き換えてください。

## 試せる操作

- イベント案内、出店一覧、お知らせ、マイページ、デモ用の支払い QR を表示する。
- チャージの照合・金額入力・現金受領確認を画面上で進め、デモ残高と履歴に反映する。
- サンプルアカウントを選んでデモ送金し、送る側と受け取る側の残高・履歴を確認する。マイページでアカウントを切り替えられる。
- 取引履歴を検索・絞り込み、詳細を確認する。マイページからデモデータを初期化する。

## デモの範囲

バックエンドには接続していません。イベント、店舗、アカウント、残高、取引はサンプルで、変更は同じブラウザーの `localStorage` に保存されます。送金はそのブラウザー内のサンプルアカウント間のみで、他の端末や実在する相手には届きません。本人認証、実際の現金受領・決済、サーバー上の台帳、QR のカメラ読み取りには対応していません。画面上の QR を実際の支払いに使用することはできません。
