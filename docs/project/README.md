## 成果物の扱い

ルートの `outputs/` はローカルの生成物・一時的な書き出し用で、Git管理から除外する。除外設定は既存ファイルを削除しない。WBSなどの手作業による変更を含む資料は、再生成できることを確認せずに削除しない。

チームで使う正式なWBS・計画資料は `docs/project/`、またはチームが合意した共有ストレージで管理し、この文書から参照できるようにする。共有する版を確認してから配置し、`outputs/` 内の資料を自動で最新版・共有済みと扱わない。
