# 担当・レビュー分担

更新日：2026-10-14。[Issue #12](https://github.com/fespay-team/fespay/issues/12)はPR #17で承認・完了済み。ユーザー指定によりFE・BE・DB・運用はnatuki53が兼任する。役割枠と実人数を区別し、5人が割り当てられたとは扱わない。

| 枠 | 主担当の範囲 | GitHubアカウント | レビュー窓口 |
| --- | --- | --- | --- |
| FE-1 | 認証・参加・残高・利用者QR・譲渡・モバイル注文 | natuki53 | fespay-team/developersの作者以外 |
| FE-2 | 主催者・受付・レジ・商品・在庫・注文・集計 | natuki53 | 同上 |
| BE-1 | 台帳・チャージ・決済・譲渡・払戻し・返金・照合 | natuki53 | 同上。台帳/認可/認証はバックエンド技術確認 |
| BE-2 | 認証認可・イベント・招待・商品在庫・注文・CSV | natuki53 | 同上。利用するFEとの契約影響を確認 |
| DB | 物理モデル・制約・排他・migration・照合/復旧検証 | natuki53 | 同上 |
| 運用 | 環境/鍵・監視・復旧・費用・終了後窓口・公開判定の記録 | natuki53 | 同上。外部/イベント主催者との合意は証跡で確認 |
| 総合 | 要件・API契約・CI・進行・公開条件・発表 | natuki53 | 同上 |

同一人物の担当枠同士の確認を作者以外のレビューへ読み替えない。個別PRのレビュー者はdevelopersチームから選び、実際の承認者/対象headをGitHubに記録する。mainの承認条件と最終push者以外の承認を維持する。

未決事項の決定窓口・期限・依存は[決定管理表](decisions.md)。natuki53は開発・運用・公開判定の窓口を兼任するが、法令判断の専門家や個々のイベント主催者の代わりに外部確認を完了扱いにしない。担当が決まったことと、公開gateが完了したことは別である。

[開発計画](../project/development-plan.md)、[GitHub設定](github-setup.md)を参照する。

AT-001～070の管理・実施窓口もnatuki53として[受入管理表](../testing/acceptance-status.md)へ同期した。作者外レビューと受入の全条件の合格は担当割当とは別に確認する。
