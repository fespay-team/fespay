# 利用マニュアル

画面と業務フローの確定後、以下を作成します。現時点では未作成です。

| 作成予定 | 読み手・内容 |
| --- | --- |
| `organizer.md` | 主催者：イベント作成、担当招待、開催制御、精算 |
| `reception.md` | 受付：現金チャージ、払戻し、結果不明・引継ぎ |
| `shop.md` | 店舗管理者・レジ担当：商品・在庫・決済・注文・返金 |
| `visitor.md` | 来場者：登録・参加・残高・支払承認・譲渡・問い合わせ |

各マニュアルには対象の画面版・関連要件・確認済み端末を記録し、未検証の操作を保証しません。
