# 来場者UIの設計確認用プロトタイプ

PR #35のU01〜U10の画面設計・クリック遷移を確認するための、React + TypeScript + Vite製の独立したアプリです。正式実装ではなく、架空のMOCKデータのみを使用します。API・DB・実認証・実金銭処理を使用しません。QRは読み取りできない仮表示で、残り時間は固定表示です。残高・在庫・現金・実取引は更新しません。

[画面一覧・遷移図](../../docs/design/ui/screen-map.md)と[来場者画面設計](../../docs/design/ui/visitor.md)を参照してください。画面コードは配置を移したもので、正式設計にあるすべての操作・例外を実装しているわけではありません。

## 起動方法

リポジトリの開発環境に合わせ、Node.js 24 / npm 11を使用します。リポジトリルートから実行してください。

```sh
cd prototypes/visitor-ui-design
npm ci
npm run dev
```

ブラウザーで <http://127.0.0.1:5174/> を開きます。停止はCtrl+Cです。PowerShellで`npm.ps1`が制限される場合は、`npm`を`npm.cmd`に置き換えてください。

専用の`package.json`・`package-lock.json`・Vite/TypeScript設定を持ち、単独で依存関係をインストールして起動します。ルートのworkspaces（`apps/*`）には含めません。ルートの`npm run dev`は従来のFesPay準備画面を起動し、ルートのtypecheck / buildもこのプロトタイプを対象にしません。APIやDBの起動、環境変数や認証情報の設定は不要です。

## build方法

このディレクトリで実行します。buildは型検査も行い、成果物を`dist/`へ出力します。

```sh
npm run typecheck
npm run build
npm run preview
```

build後のプレビューは <http://127.0.0.1:4174/> です。

## 確認できる画面・導線

| 画面 | 確認できる操作 |
| --- | --- |
| U01 認証 | メール／GoogleのMOCKログインからU02へ。実際の認証は行わない |
| U02 イベント一覧・案内 | 検索、イベント選択、開催情報・条件の表示からU03へ |
| U03 参加・条件同意 | 既参加確認、条件同意、MOCK参加パスワード確認からU04へ |
| U04 イベントホーム | 残高3区分・最終確認時刻、U05〜U08・U10への入口、イベント選び直し |
| U05 支払いQR | B方式の仮QR・固定の有効期限表示、ホームへ戻る |
| U06 チャージ・現金払戻し | 受付仮QR・表示名・照合番号、チャージ結果／結果確認中／払戻しのMOCK状態、履歴への導線 |
| U07 送る・受け取る | 受取仮QR、相手確認→金額→確認→MOCK完了→履歴、各ステップの戻り |
| U08 商品・カート | 商品追加・数量変更→カート→注文確認→MOCK支払→U09、既存注文への入口 |
| U09 注文・受取 | 注文一覧→詳細→受取画面、商品・履歴・ホームへの戻り |
| U10 履歴・問い合わせ | 種別絞込み→詳細→架空の問い合わせ先・追跡ID、一覧への戻り |

「みなと秋まつり」は参加済み・残高ありのMOCKで、U04以降の操作確認に使えます。「桜ヶ丘学園祭」は未参加・残高0のMOCKで、条件同意と参加パスワード（画面のヒントに表示される`fespay-demo`）を確認できます。後者では譲渡・モバイル注文が無効です。

カートありのイベント切替では、「戻る」でカートを保持し、「破棄して切り替える」で破棄する導線を確認できます。ログイン・参加・カート・MOCK完了の状態はメモリ内のみで、再読み込みすると初期状態へ戻ります。認証とイベント選択を経て操作してください。
